# Rainfall Prediction

A machine learning web application that predicts rainfall based on weather parameters.

## Technologies Used
- Python
- Flask
- Pandas
- NumPy
- Scikit-learn

## Project Structure
- app.py
- src/train_model.py
- templates/index.html
- requirements.txt

## How to Run
1. Install dependencies
2. Train the model
3. Run app.py
